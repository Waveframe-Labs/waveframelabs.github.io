Execution Control

CRI-CORE

What actually stops an AI system from executing a bad decision?

CRI-CORE sits at the execution boundary and decides:

✓ allow this action
✗ block it before it happens

Install

pip install cricore

PyPI: cricore
GitHub: CRI-CORE

What it does

  • Evaluates every proposed action before execution
  • Enforces roles, approvals, and constraints
  • Validates integrity and required artifacts
  • Applies deterministic contract checks
  • Returns a single decision: true | false

Why it exists

AI systems can now:

move money · deploy code · approve decisions

Most systems: detect problems or log them after the fact

CRI-CORE: prevents the action from happening in the first place

Where it fits

CRI-CORE is the final step before execution.

It does not generate actions. It does not interpret meaning. It does not make policy decisions.

It only decides: does this action execute or not?
