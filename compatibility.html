Recommended install set

The shortest current public path is:

pip install "waveframe-guard==0.19.0"

For an explicitly pinned reproducible environment:

pip install "waveframe-guard==0.19.0" "governance-ledger==0.9.0" "cricore==0.13.0" "cricore-contract-compiler==0.5.0" "cricore-proposal-normalizer==0.2.0"

CRI-CORE v0.14.0 remains a GitHub release rather than the ordinary PyPI baseline. Guard 0.19.0 accepts cricore>=0.13.0,<0.15.0; ordinary index installation therefore continues to resolve CRI 0.13.0.

Runtime boundary rules

Mediation

  • Guard protects the wrapped callable path, not the entire machine, agent, repository, or credential set.
  • Direct calls or alternate APIs can bypass a wrapper unless deployment permissions remove those paths.
  • Repository mutation assurance requires repository_tool and its bound repository target.

Action + target scope

  • Compiler 0.5.0 action policies define create and modify independently, including required role plus literal exact/prefix allow and deny selectors.
  • Selectors are case-sensitive and literal; deny rules take precedence.
  • Absent action authority, missing targets, malformed selectors, or unmatched targets do not grant permission.

CRI modes

  • Published PyPI 0.13.0 remains the ordinary-install baseline.
  • GitHub v0.14.0 defaults omitted mode to strict.
  • v0.14.0 accepts only explicit strict or local; configuration conflicts reject before policy evaluation.

Authority identity

  • Authority references are explicit and versioned.
  • Contract id, version, and hash remain bound through proposal and evaluation.
  • Ledger 0.9.0 catalog 3 preserves independent create/modify approval and publication identity through the runtime boundary.
