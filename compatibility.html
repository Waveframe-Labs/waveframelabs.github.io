Recommended install set

For the current published runtime path:

pip install "waveframe-guard==0.18.0" "cricore==0.13.0" "cricore-contract-compiler==0.4.0" "cricore-proposal-normalizer==0.2.0"

For governance publication:

pip install "governance-ledger==0.8.0"

Do not use governance-ledger[guard]==0.8.0 to obtain the current Guard release; that extra selects Guard 0.17.0.

Runtime boundary rules

Mediation

  • Guard protects the wrapped callable path, not the entire machine, agent, repository, or credential set.
  • Direct calls or alternate APIs can bypass a wrapper unless deployment permissions remove those paths.
  • Repository mutation assurance requires repository_tool and its bound repository target.

Target scope

  • Compiler 0.4.0 emits literal exact/prefix target requirements.
  • Rules are case-sensitive; deny rules take precedence.
  • Missing or malformed target data fails closed when scoped authority requires it.

CRI modes

  • Published PyPI 0.13.0 remains the ordinary-install baseline.
  • GitHub v0.14.0 defaults omitted mode to strict.
  • v0.14.0 accepts only explicit strict or local; configuration conflicts reject before policy evaluation.

Authority identity

  • Authority references are explicit and versioned.
  • Contract id, version, and hash remain bound through proposal and evaluation.
  • Ledger v3 adds publication commitment and receipt evidence without changing the v2 compiled runtime payload.
