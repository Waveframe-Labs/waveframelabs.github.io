Layer 5 — Tools & Infrastructure

Purpose

The tools built under Waveframe Labs exist to make governance practical. They encode doctrine, governance, and workflow rules directly into PDFs, metadata, and validation pipelines.

Waveframe PDF Forge

Static PDF generator tailored for research artefacts. Inserts metadata headers, provenance information, and consistent styling for institutional documents.

Repository: Waveframe-Labs/Waveframe-pdf-Forge (currently private).

Stamp (Metadata Injector)

Planned command-line utility to inject and validate metadata headers across repositories. It will ensure that every file carries the required provenance, licensing, and governance information.

Status: design + MVP phase; will integrate with AWO and CRI-CORE validators.

Metadata Pipeline

Conceptual pipeline that connects source repositories, Stamp, validators, PDF Forge, and DOI / OSF submission steps into a single, reproducible process.

Status: being specified alongside AWO v1.3.x and CRI-CORE architecture.

Validator Suite

A growing collection of checks (metadata, directory structure, checksums, doctrine compliance) that will eventually fold into the CRI-CORE runtime.

Status: early prototypes; see AWO and CRI-CORE repositories for details.
