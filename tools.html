Layer 5 — Tooling & Infrastructure

Why tools are a separate layer

Tooling is not the method itself. Waveframe Labs treats tools as downstream infrastructure that must implement — not redefine — the doctrine, ARI decisions, and AWO/CRI-CORE contracts.

Current Tooling Stack

Waveframe PDF Forge

Internal PDF generator for building release-grade documents from Markdown and HTML with metadata headers and institutional branding.

Repository: private (Waveframe-Labs/Waveframe-pdf-Forge).

Waveframe Stamp

Metadata injector for applying standardized headers to documents and code files across AWO and governance repos.

Planned public release after v1.0 stabilization.

Validator Suite

Early validators for metadata presence, directory structure, checksums, and doctrine compliance — serving as precursors to full CRI-CORE.
