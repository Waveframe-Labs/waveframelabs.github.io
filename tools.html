Open components by execution-governance layer.

The open stack separates policy publication, deterministic compilation, proposal shape, admissibility evaluation, and runtime mediation. Commercial Cloud, Console, Ledger Workspace, Guard Inspector, and multi-tenant operations remain separate product surfaces.

Current developer path

pip install waveframe-guard==0.18.0

Guard 0.18.0 wraps the customer's existing mutation callable. It works with custom agents and common orchestration frameworks without requiring a Waveframe-specific agent loop.

Guard protects the callable path that is actually wrapped. Direct access to the original function, another API, shell, process, or credential path is outside that enforcement guarantee unless deployment permissions independently remove the bypass.

Layered ecosystem

Governance

Waveframe Ledger 0.8.0

Authoring / Publication

Turns supported policy meaning into reviewable, publishable authority while preserving unsupported or residual meaning instead of silently guessing it. v0.8.0 adds human-confirmed untrusted translation proposals and native v3 publication evidence.

ConsumesSource policy, capability/domain constraints, human decisions
EmitsPublished authority, bundles, commitments, receipts, lineage
Does notRun enforcement or make model output authoritative

Install: pip install governance-ledger==0.8.0

Admissibility Kernel

Evaluates a canonical proposal against compiled authority and returns the deterministic commit decision. PyPI currently provides 0.13.0. GitHub v0.14.0 is released with strict-by-default evaluation, while its release record still marks PyPI publication pending.

PyPI baselinecricore==0.13.0

Runtime

Waveframe Guard 0.18.0

Mediated Execution Boundary

Guard.local() and Guard.cloud() wrap sensitive tools, resolve/verify authority, evaluate immediately before callback execution, and block the callback when authority does not permit it. Repository writes use the stronger repository_tool boundary and a bound RepositoryTarget.

ConsumesActual tool call, actor identity, explicit authority ref
EmitsDecision plus execution/mutation evidence
Does notGenerate actions, author policy, or sandbox the entire process

Install: pip install waveframe-guard==0.18.0

Waveframe Cloud

Commercial Operations Plane

Hosts authority distribution, runtime identity, evidence preservation, receipts, and Console operations. v0.5.7 is the latest published Cloud release. Newer Ledger v2/v3 serving and translation workflow work has merged in source but is not represented here as a newer deployed release.

ConsumesPublished authority and governed evidence
EmitsRegistry/publication responses, receipts, operational views
Does notReplace Guard's local admissibility decision

30-second integration shape

from waveframe_guard import Guard

guard = Guard.cloud(
    authority="budget-quickstart@1.0.0",
    actor_identity={"id": "budget-agent", "type": "agent", "role": "allocator"},
)

guarded_allocate = guard.tool(
    action="allocate_budget",
    target="account_id",
    include_arguments=("amount",),
)(allocate_budget)

Expose guarded_allocate to the agent instead of the original mutation callable. For repository mutation, use the documented repository_tool API rather than a generic callback.
