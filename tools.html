Execution Tooling

Tools

These tools form a simple pipeline:

define what is allowed → normalize the action → decide if it executes

Execution Control

CRI-CORE

The enforcement layer. It decides whether a proposed action is allowed to execute.

Input: a proposed action Output: commit_allowed = true | false

Install: pip install cricore
PyPI: cricore
GitHub: CRI-CORE

Input Pipeline

Contract Compiler

Converts real policies (roles, approvals, constraints) into a format CRI-CORE can enforce.

Install: pip install cricore-contract-compiler

Proposal Normalizer

Converts an action (from AI or a system) into a standardized structure that CRI-CORE can evaluate.

Install: pip install cricore-proposal-normalizer

Validation & Output

Stamp

Validates metadata and artifacts before execution or publication.

Install: pip install waveframe-stamp
PyPI: waveframe-stamp

Forge

Generates finalized outputs and publication artifacts.
