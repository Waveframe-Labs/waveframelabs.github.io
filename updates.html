2026 · SEP 09

CRI-CORE v0.14.0 — Strict-by-default evaluation

Changed omitted public evaluation mode to strict. Advisory evaluation now requires explicit mode="local"; invalid or conflicting mode declarations reject before policy evaluation. The GitHub release is published, but its release record states that PyPI publication and fresh external installation remain pending.

2026 · SEP 08

Waveframe Guard v0.18.0 — Mediated execution boundary

Published the current Guard Core SDK under Apache-2.0, bounded runtime dependencies, fail-closed legacy API migration, explicit bypass/least-privilege guidance, and repository-bound mutation through repository_tool. Guard protects the wrapped callable path; it does not claim global control over alternate mutation paths.

Read the release →
2026 · SEP 05

Waveframe Ledger v0.8.0 — Human-confirmed translation and native v3 publication

Added an untrusted policy-translation proposal boundary in which each proposed control requires human confirmation before it can become authority. Native v3 publication binds confirmed controls, residual unsupported meaning, source/approval identity, Constraint IR, and matching receipt evidence while retaining the v2 compiled runtime payload.
